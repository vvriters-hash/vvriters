## 1. Из чего складывается себестоимость

Сервер почти ничего не стоит. **~95 % затрат — внешние API**: ИИ-модели, данные соцсетей, генерация картинок. Поэтому считаем себестоимость одного проекта.

### 1.1 Цены на входе

| Ресурс | Что берём | Цена |
|---|---|---|
| Claude Sonnet 5 — основная модель (бриф, синтез, идеи, сценарии) | за 1 млн токенов | $2 вход / $10 выход; чтение из кэша — ~10 % от входа |
| Claude Haiku 4.5 — массовые простые задачи (разбор кадров, ранжирование) | за 1 млн токенов | $1 / $5 |
| Claude Opus 5 — премиум-качество текста | за 1 млн токенов | $5 / $25 |
| Распознавание речи — OpenAI gpt-4o-mini-transcribe | минута аудио | ~$0,003 |
| Картинки — OpenAI GPT Image 2 | 1 картинка 1024×1024 | низкое ~$0,006 · среднее ~$0,053 · высокое ~$0,211 |
| Данные соцсетей — ScrapeCreators | 1 000 запросов | $1,88 (пакет $47) … $0,99 (пакет $497) |
| Скачивание видео (прокси/трафик) | 1 ролик ~10 МБ | ~$0,01 (оценка) |

### 1.2 Допущения по «стандартному проекту»
Из ответа «4–5 проектов в месяц, по ~10 рилс в проекте»:
- бриф: 10 минут голосовых + 1–2 документа, диалог с агентом;
- аналитика: **30 роликов**, по каждому 8 кадров + расшифровка + ~150 комментариев;
- идеи: 3 генерации по 10 логлайнов;
- **10 сценариев**, каждый — генерация + 3 ИИ-правки;
- раскадровка: 10 сценариев × ~12 кадров × 1,3 (перегенерации) ≈ **156 картинок** низкого качества (эскиз);
- +15 % на повторы, ошибки и служебные вызовы.

### 1.3 Себестоимость стандартного проекта

| Шаг | Как считали | $ |
|---|---|---|
| Ресёрч | распознавание 10 мин ($0,03) + разбор и диалог на Sonnet (~40k токенов на вход, ~6k на выход) | 0,17 |

| Сводка и отчёт | Sonnet | 0,16 |
| Идеи | Sonnet с кэшированием контекста | 0,20 |

**Только аналитика (MVP: бриф + 30 роликов + отчёт): ≈ $2,5 ≈ 225 ₽.**

### 1.4 Три режима качества

| Режим | Что меняется | $ за проект | ₽ |
|---|---|---|---|
| Эконом | 20 роликов, Haiku на разборе, 5 сценариев, 60 кадров | ≈ 3 | ≈ 270 |
| **Стандарт** | как в 1.3 | **≈ 6** | **≈ 530** |
| Премиум | Opus 5 на выводах и сценариях, картинки среднего качества | ≈ 18 | ≈ 1 600 |

**Главный вывод:** в премиуме дороже всего **картинки среднего качества** (~$8 из $18). Поэтому раскадровка по умолчанию идёт эскизами, а «чистовые» кадры тратят кредиты отдельно.

### 1.5 Рычаги снижения себестоимости
1. **Кэширование промптов**: общий контекст проекта (бриф + сводка) кэшируется, повторное чтение стоит ~10 % цены. Уже заложено.
2. **Кэш роликов**: популярный ролик, разобранный для одного пользователя, не качаем и не разбираем повторно 7 дней. Экономия растёт с числом пользователей в одной нише.
3. **Пакетная обработка (Batch API, −50 %)** — для ночного мониторинга трендов. Для аналитики «за 10 минут» не подходит: пакет может обрабатываться дольше.
4. **Дешёвая модель на массовых шагах** (Haiku для извлечения, Sonnet/Opus только для выводов).
5. **Правки по строке, а не по всему сценарию.**

## 2. Кредиты
Пользователь покупает подписку, а внутри тратит кредиты. Так пользователь, который генерирует в 10 раз больше среднего, не уводит тариф в минус.

**1 кредит ≈ $0,01 себестоимости с запасом** (по факту ~0,8 ₽).

| Действие | Кредитов |
|---|---|
| Разбор брифа (с диалогом) | 20 |
| Анализ 1 ролика (данные + видео + разбор) | 7 |
| Сводка / отчёт | 20 |
| Пачка из 10 идей | 10 |
| Сценарий (генерация) | 15 |
| ИИ-правка сценария | 3 |
| Кадр раскадровки — эскиз | 1 |
| Кадр раскадровки — чистовой (среднее качество) | 7 |
| **Стандартный проект целиком** | **≈ 680** |
| **Только аналитика на 30 роликов** | **≈ 250** |

Экспорт, редактирование вручную и комментарии — бесплатно.

## 4. Модель на 1 000 платящих подписчиков

Структура (допущение): 50 % Старт, 40 % Креатор, 10 % Про. Плюс ~2 000 новых бесплатных регистраций в месяц. Юрлицо — Грузия.

> ⚠️ Грузинское юрлицо не принимает карты российских банков. 1 000 платящих — это креаторы с зарубежными картами и зарубежный рынок, поэтому цены в рублях здесь — только для удобства сравнения.

| Статья | ₽ в месяц | Комментарий |
|---|---|---|
| **Выручка** | **5 190 000** | 500 × 1 990 + 400 × 5 990 + 100 × 17 990 |
| API (платящие) | −1 264 000 | использование 80 % / 60 % / 60 % |
| API (бесплатные) | −168 000 | 2 000 × 150 кр. × 0,8 ₽ × 70 % — по сути затраты на привлечение |
| Платёжка | −304 500 | merchant of record (Paddle или аналог): ~5 % + $0,5 за платёж |
| Налоги (Грузия) | −51 900 | 1 % с оборота (ИП со статусом малого бизнеса). **Но** при таком обороте (~62 млн ₽ в год) порог в 500 тыс. лари будет превышен → переход на LLC: налог на прибыль при выводе денег или 0 % в «Виртуальной зоне». Считать с грузинским бухгалтером |

**Расход на API при 1 000 подписчиках:** ≈ $16 000 в месяц. Это важно для лимитов у провайдеров: нужны высокие уровни доступа (тиры) у Anthropic и OpenAI, их получают по мере роста трат.

## 5. Нагрузка и серверы

### 5.1 Что значит «1 000 подписчиков» в цифрах
| Метрика | Значение |
|---|---|
| Проектов в месяц | ~2 300 (≈ 80 в день) |
| Роликов на анализ | до ~70 000 в месяц |
| Запросов к провайдеру данных | ~420 000 в месяц |
| Вызовов ИИ | ~470 000 в месяц, в пике ~300 в минуту |
| Картинок | до ~360 000 в месяц, в пике ~50 в минуту |
| Одновременно онлайн в пике | ~150 человек |
| Параллельных аналитических задач в пике | 10–15 (по 10 роликов в каждой → до 150 роликов в обработке) |
| Рост хранилища | ~125 ГБ в месяц (картинки + кадры). Кадры роликов удаляем через 90 дней |

**YouTube Data API:** бесплатной квоты (10 000 единиц в день, поиск = 100 единиц) хватит примерно на 100 поисков в день. При 1 000 подписчиков нужна заявка на увеличение квоты или поиск по YouTube через агрегатор.

### 5.2 Сервера (при 1 000 подписчиках)
| Компонент | Конфигурация | Примерно $ в месяц |
|---|---|---|
| Веб + API | 2 × (4 vCPU, 8 ГБ) + балансировщик | 40–80 |
| Совместное редактирование | 1 × (2 vCPU, 4 ГБ) | 10–20 |
| Воркеры (скачивание, ffmpeg, конвейер) | 3 × (8 vCPU, 16 ГБ), автомасштабирование | 100–250 |
| PostgreSQL | 8 vCPU, 32 ГБ + реплика, бэкапы | 100–250 |
| Redis | 2–4 ГБ | 15–40 |
| S3-хранилище | 1–2 ТБ в год | 20–50 |
| Прокси для скачивания видео | по трафику | 100–300 |
| Мониторинг, логи, почта, Sentry | | 50–150 |
| **Итого** | | **≈ 450–1 150** (в модели заложено ≈ 1 350 = 121 000 ₽ с запасом) |

На старте (до 100 подписчиков) хватит **2–3 серверов за $50–100 в месяц**. У крупных облаков (AWS, GCP) та же конфигурация обойдётся в 2–3 раза дороже; для MVP это не нужно.

### 5.3 Где размещать
Юрлицо — Грузия (см. [DECISIONS.md](DECISIONS.md#2-юрлицо-и-размещение)). Коротко:
- **Основной контур** (приложение, воркеры, файлы) — в Европе (Германия или Финляндия): близко и к РФ, и к Грузии, есть доступ к зарубежным API.
- **Пользователи из РФ:** если юрист подтвердит, что 152-ФЗ требует хранить их персональные данные (email, имя, телефон) в РФ, — отдельная база в Yandex Cloud или Selectel.

## 6. Провайдеры данных соцсетей: сравнение

| Вариант | Модель оплаты | Цена | Плюсы | Минусы | Для чего |
|---|---|---|---|---|---|
| **ScrapeCreators** | оплата за запросы, кредиты не сгорают | $1,88 → $0,99 за 1 000 запросов | нет абонплаты, TikTok + IG + YT одним API | зависимость от одного поставщика | **MVP, основной** |
| EnsembleData | подписка с дневными лимитами (без переноса) | $100–1 400 в месяц | стабильная цена при ровной нагрузке | лимиты сгорают каждый день, тяжёлые запросы по IG до 10 единиц | при стабильном объёме |
| Apify (готовые парсеры) | за результат + тариф платформы | $0,2–2 за 1 000 результатов | дёшево, много вариантов | качество и стабильность зависят от автора парсера, цену сложно предсказать | **резерв** |
| YouTube Data API (официальный) | бесплатно по квоте | 0 | официально, стабильно | только YouTube, квота | **Shorts** |
| TikTok Research API / Instagram Graph API | — | — | официально | для коммерческого сервиса фактически недоступны | не подходит |
| Свой парсинг | прокси + разработка | дешевле всего на больших объёмах | полный контроль | постоянные поломки, блокировки, юридический риск | после 3–5 тыс. проектов в месяц |

**Решение:** ScrapeCreators (основной) + Apify (резерв) + YouTube Data API, за общим интерфейсом `DataProvider`. На объёме 1 000 подписчиков (~420 тыс. запросов в месяц) — пакет $497 на 500 тыс. запросов ≈ **$420–500 в месяц**.

## 7. Что проверить в Фазе 0
1. Реальная себестоимость проекта (цель: ≤ $6 стандарт, ≤ $2,5 аналитика).
2. Скорость: 30 роликов ≤ 10 минут.
3. Доля роликов, которые не удалось получить через провайдера (цель < 5 %).
4. Качество разборов «почему залетел» на эталонных брифах — твоя оценка по шкале 1–5.
5. Скачивание видео без дорогих прокси: есть ли у провайдера прямые ссылки на файл.
