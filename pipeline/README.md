# Конвейер аналитики (Фаза 0)

Прототип без интерфейса: **бриф → стратегия поиска → поиск роликов → отбор топовых → разбор каждого ролика → сводка → отчёт** с подсчётом себестоимости каждого шага. Цель Фазы 0 (docs/TZ.md §3, docs/ECONOMICS.md §7) — измерить реальное качество разборов и себестоимость до разработки интерфейса.

## Что умеет
- **Бриф** из любых материалов: текст, `.txt/.md`, PDF, фото/скриншоты, голосовые и видео (расшифровка OpenAI). Результат — бриф по полям + уточняющие вопросы клиенту.
- **Стратегия поиска** на языке аудитории: ключевые слова и хэштеги для TikTok, Reels, Shorts.
- **Поиск и отбор**: ScrapeCreators → фильтр по периоду и просмотрам → релевантность (Haiku) → коэффициент выброса (просмотры / медиана автора) → итоговый балл.
- **Разбор ролика**: 8 кадров (ffmpeg), своя расшифровка речи, топ-150 комментариев, цифры → карточка: хук, структура, формат, комментарии, «почему залетел» **с доказательствами**, что взять в проект.
- **Сводка**: закономерности, вопросы зрителей, незанятые углы, направления для роликов.
- **Отчёт**: `report.md` и `report.html` (тёмная тема VVriters) + таблица себестоимости по шагам, `costs.jsonl` — каждый платный вызов.

## Запуск
Локально:
```bash
npm ci
MOCK=1 npm run dev -- run --brief fixtures/mock/brief-example.txt --count 5   # без ключей
npm test
```
На сервере — через `deploy/vv` (см. deploy/README.md).

## Настройки
Все — через переменные окружения (`deploy/.env.example`). Модели меняются без правки кода: `MODEL_MAIN`, `MODEL_FAST`, `MODEL_VIDEO` — например, чтобы сравнить качество разборов на Sonnet 5 и Opus 5.

## Структура
| Путь | Что |
|---|---|
| `src/cli.ts` | Команды `run`, `analyze-url`, `check` |
| `src/steps/` | Шаги конвейера: brief, strategy, search, rank, analyze, synthesize |
| `src/providers/` | Слой `DataProvider`: ScrapeCreators, тестовый провайдер, нормализация ответов |
| `src/ai/` | Claude (структурированный вывод, кэш промптов, учёт токенов), распознавание речи |
| `src/media.ts` | Скачивание (прямая ссылка → yt-dlp), кадры и звук через ffmpeg |
| `src/cost.ts` | Цены и учёт себестоимости |
| `src/report.ts` | Отчёт Markdown/HTML |
| `fixtures/mock/` | Тестовые данные для режима `MOCK=1` |

## Известные ограничения прототипа
- Схемы ответов ScrapeCreators нормализуются «с запасом» по нескольким возможным полям; сырые ответы сохраняются в `raw/` — после первых реальных прогонов сверим и уточним.
- YouTube Shorts скачиваются через yt-dlp; с IP дата-центра YouTube может блокировать — тогда разбор идёт без кадров (по расшифровке, цифрам и комментариям) и это видно в отчёте.
- DOCX в брифе пока не читается — сохраните как PDF.
- Отчёт пока на русском в заголовках; содержимое — на языке `--lang`.
