# Тестовый стенд на VPS

Сервер заказчика: Австрия, Debian 13, 2 vCPU, 3,8 ГБ RAM (свободно ~2,3 ГБ), 125 ГБ диска, swap нет.
На сервере уже работает Hermes (в контейнере) — его не трогаем.

## Шаг 1. Проверка (ничего не меняет)
Зайди на сервер по SSH — **на сам сервер, не внутрь контейнера Hermes** — и выполни:
```bash
curl -fsSL https://raw.githubusercontent.com/vvriters-hash/vvriters/claude/youthful-davinci-k0rx6v/deploy/check.sh -o check.sh
bash check.sh
```
Пришли весь вывод в чат.

> Если репозиторий приватный и `curl` вернёт 404 — открой файл `deploy/check.sh` на GitHub, скопируй содержимое в `nano check.sh` на сервере и запусти `bash check.sh`.

## Шаг 2. Подготовка (после того как я посмотрю вывод шага 1)
```bash
curl -fsSL https://raw.githubusercontent.com/vvriters-hash/vvriters/claude/youthful-davinci-k0rx6v/deploy/setup.sh -o setup.sh
sudo bash setup.sh
```
Что делает: включает swap 4 ГБ, ставит Docker (если его нет), ограничивает размер логов Docker, создаёт папку `/opt/vvriters`.
Чего не делает: не трогает файрвол, SSH и уже работающие контейнеры (Hermes). Повторный запуск безопасен.

## Бюджет памяти для прототипа
| Компонент | Лимит |
|---|---|
| PostgreSQL | 384 МБ |
| Redis | 128 МБ |
| API + воркер (Node.js) | 768 МБ |
| Веб (Next.js) | 384 МБ |
| Caddy (HTTPS) | 64 МБ |
| ffmpeg (пиково, 1 задача) | ~300 МБ |
| **Итого** | **~2 ГБ** + swap 4 ГБ как страховка |

Чтобы уложиться:
- Файлы храним на диске сервера (без отдельного S3-хранилища MinIO) — переключим на S3 при переезде в прод.
- Docker-образы **собираются в GitHub Actions**, а сервер только скачивает готовые: сборка Next.js на 2 ядрах и 2 ГБ памяти может упасть по нехватке памяти.
- Одна аналитическая задача за раз, ffmpeg в 1 поток. 30 роликов будут обрабатываться ближе к 10–15 минутам, а не к 5–10 — для теста нормально.

## Адрес без своего домена
Пока домена нет, используем бесплатный адрес по IP сервера: `https://<ip-через-дефисы>.sslip.io` (его покажет `check.sh`). HTTPS-сертификат выпустится автоматически.
Ограничения: вход через Google с таким адресом может не пройти проверку — на время теста вход по email-коду. Telegram-бот работает без домена.
**До закрытой беты** лучше купить домен (~$10–15 в год) — адрес на sslip.io выглядит несерьёзно для клиентов в портале.

## Секреты
Ключи API — только в файле `/opt/vvriters/.env` на сервере (`chmod 600`). Не отправляй их в чат и не коммить в репозиторий.
